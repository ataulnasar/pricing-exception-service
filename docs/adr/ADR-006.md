# ADR-006: Runs locally with H2; Postgres profile; Flyway owns the schema

**Status:** Accepted

## Context

The assignment asks for an easy local run with no paid or private services (R6, C2). The
service should also run on a real database.

## Decision

- The default profile uses in-memory H2 and loads seed data.
- The `postgres` profile uses PostgreSQL on `localhost:5432` and loads no seed data.
- Flyway owns the schema. Migrations are in `db/migration`. Seed data is in `db/seed` and only
  the default profile loads it.
- Hibernate runs with `ddl-auto=validate`. It checks the entities against the schema and does
  not change it.
- The SQL is portable, so the same migrations run on both databases.

## Consequences

Good:
- `./mvnw spring-boot:run` works with no install.
- The same schema runs on H2 and PostgreSQL.

Bad:
- H2 data is lost on restart.
- The enum CHECK constraints are missing, see `docs/runbook.md` "Known issues".
- The `postgres` profile has placeholder credentials.

## Proved by

- `PricingExceptionServiceApplicationTests.contextLoads`
- `PostgresMigrationTest` (class: runs the migrations and seed data on PostgreSQL)
